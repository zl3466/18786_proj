│    Format: "skeleton | actual_sql"                                           │
│    Example: "select count ( _ ) from _ where _ | select count ( * ) from..." │
│    Benefit: +10-11% accuracy improvement                                     │

└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ 3. LOSS MASKING                                                              │
│    System/User messages: Masked (no loss)                                    │
│    Assistant messages: Loss computed                                         │
│    Result: Model learns to generate responses only                           │
